# Phase 4 · Industry Handoff (≈6 weeks)

**Goal:** take the research-and-applied skills built so far and meet a real production standard — the "ship it and keep it running" side of ML.

> ⚙️ *Align the tools listed with the actual stack you taught (Docker, FastAPI, MLflow, GitHub Actions all appear in your profile).*

## What interns learned
- **From model to service:** wrapping a model in an API (e.g. FastAPI), input validation, sane error handling.
- **Packaging & deployment:** Docker, reproducible builds, deployment basics.
- **MLOps fundamentals:** experiment/model versioning, CI/CD for ML (e.g. GitHub Actions), and why pipelines beat notebooks in production.
- **Monitoring & maintenance:** data drift, model decay, and what "done" actually means once something is live.
- **Cost & efficiency awareness:** the difference between a model that works in a notebook and one that's affordable at scale.

## The crossover move
Where possible, interns took the model from their **research month** or **applied project** and *deployed it* — proving the bridge in a single artifact: a research-grade idea, shipped and monitored. That crossover project became the centerpiece of their portfolio.

## Deliverable
A containerized, deployed model with basic monitoring and a CI pipeline — reproducible by anyone from the repo.

## Assessed on
Reliability, reproducibility, and production-readiness — plus the strength of the crossover project. See the [rubric](../evaluation/rubric.md).
