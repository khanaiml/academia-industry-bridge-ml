# Contributing

This repo documents a real program, but the curriculum and resources are meant to be improved and adapted.

Welcome contributions:
- Fixes to broken links or outdated resources.
- Better or newer resources for any phase.
- Adaptations for other cohorts (share what worked for you).

## How
1. Fork the repo.
2. Create a branch: `git checkout -b improve-phase-3-resources`.
3. Make your change and commit with a clear message.
4. Open a pull request describing what and why.

Keep additions concise and evidence-based — the value of this repo is that it's grounded in a real program, not a link dump.
