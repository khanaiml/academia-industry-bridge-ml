# 🎥 Courses

Free unless noted. Finish one before starting the next — completion beats collection.

## Foundations
- **3Blue1Brown — Essence of Linear Algebra & Essence of Calculus** (YouTube). Unbeatable intuition.
- **Khan Academy — Statistics & Probability.** Solid, free, structured.

## Core Machine Learning
- **Machine Learning Specialization** — Andrew Ng (Coursera / DeepLearning.AI). The classic on-ramp.
- **Machine Learning** — Google's Machine Learning Crash Course. Fast and practical.
- **CS229: Machine Learning** — Stanford (lecture notes + videos). The rigorous version.

## Deep Learning
- **Deep Learning Specialization** — Andrew Ng (DeepLearning.AI).
- **Practical Deep Learning for Coders** — fast.ai. Top-down, code-first, industry-minded.
- **CS231n** — Stanford (Vision), **CS224n** — Stanford (NLP). Research-grade depth.
- **Neural Networks: Zero to Hero** — Andrej Karpathy (YouTube). Build everything from scratch, including a mini-GPT.

## LLMs & Modern AI
- **Hugging Face — LLM / NLP Course.** Free, hands-on, current.
- **Karpathy — "Let's build GPT" / "Let's reproduce GPT-2"** (YouTube).

## Industry / MLOps
- **Made With ML** — Goku Mohandas. The end-to-end applied-ML + MLOps course.
- **Full Stack Deep Learning** — lectures on shipping ML products.

## Research
- **Papers with Code** — not a course, but the fastest way to pair papers with runnable implementations.

> 💡 Watch at 1.5×, but *do every exercise*. Passive watching teaches almost nothing.
