# 📚 Books

Opinionated picks. Read *one* per topic, cover to cover, before buying the next.

## Foundations (Math & Stats)
- **Mathematics for Machine Learning** — Deisenroth, Faisal, Ong. *(Free PDF online; the perfect ML-focused math primer.)*
- **Think Stats** — Allen Downey. *(Practical, Python-based statistics; free.)*
- **An Introduction to Statistical Learning (ISLP)** — James, Witten, Hastie, Tibshirani. *(The gentle classic; free PDF, now with Python.)*

## Core Machine Learning
- **Hands-On Machine Learning with Scikit-Learn, Keras & TensorFlow** — Aurélien Géron. *(The best single practical ML book. Start here.)*
- **The Elements of Statistical Learning (ESL)** — Hastie, Tibshirani, Friedman. *(The rigorous reference; free PDF. Advanced.)*
- **Pattern Recognition and Machine Learning** — Christopher Bishop. *(The Bayesian classic. Advanced.)*

## Deep Learning
- **Deep Learning** — Goodfellow, Bengio, Courville. *(The foundational textbook; free online.)*
- **Dive into Deep Learning (d2l.ai)** — interactive, code-first, free, and constantly updated.
- **Understanding Deep Learning** — Simon Prince. *(Modern, beautifully illustrated; free PDF.)*

## Industry / MLOps
- **Designing Machine Learning Systems** — Chip Huyen. *(The definitive production-ML book.)*
- **Machine Learning Design Patterns** — Lakshmanan, Robinson, Munn.
- **Building Machine Learning Powered Applications** — Emmanuel Ameisen.

## Research skills
- **The Craft of Research** — Booth, Colomb, Williams. *(How to ask and answer a research question.)*
- **Writing for Computer Science** — Justin Zobel.

> 💡 Many of these are legally free from the authors. Prefer the free official version over any pirated copy.
